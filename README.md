# **Planets_Assignment 🪐🚀**
⭐The Planets - Solar System Explorer⭐

Here I have created an interactive C# console application that stores and manages data for the planets in our solar system. This project demonstrates OOP fundamentals such as classes, list management, and input validation.

***🚀 Features***
- **Contains a Side by Side Display:** This allows user to view all planets in a clean, two-column layout
- **Search Functionality:** Allows user to look up specific mass and distance data
- **Moon Tracker:** Allows user to iew the names and counts of moons for each planet
- **Solar System Validation:** This Checks if a specific object is recognised in the database

***🛠️ Technology Info***
- **Language:** C# 
- **Architecture:** Object Oriented Programming 

***📋 Test Plan***
My planet Console Application was tested against the following scenarios:
1. **Case Sensitivity:** Verified that searching "mars" or "MARS" returns the correct data 
2. **Input Validation:** Ensured that invalid menu choices for example by entering "9" does not crash the entire program
3. **Data Integrity:** Confirmed that Pluto and all dwarf planets display correctly despite list length
handling for console buffer limits, and generating information. Directions for users was also provided to ensure the code met specific assignment criteria making it user friendly for all and all logical structures.
